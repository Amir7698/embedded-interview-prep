# AI Banner Image Prompts

Use one of these prompts in **Midjourney**, **DALL-E 3**, or **Adobe Firefly**
to generate the GitHub repo banner.

---

## Prompt 1 — Dark Tech / Code Aesthetic (Recommended)
Best for: Midjourney, DALL-E 3

```

C code with register definitions and interrupt handlers, oscilloscope waveforms,
STM32 microcontroller PCB in foreground, green and cyan monospace code text glowing
on screens, soldering iron nearby, CAN bus and UART protocol diagrams visible,
dramatic cinematic lighting, professional software engineering aesthetic,
16:9 banner format, no text overlay needed, hyper-realistic, ultra-detailed
```

## Tips

- **Midjourney**: add `--ar 4:1` for wide banner, `--v 6` for best quality
- **DALL-E 3**: copy prompt exactly, add "make it wide/banner format"
- **Adobe Firefly**: works well with Prompt 2 (cleaner results)
- For adding text: generate the image, then open in **Canva** or **Figma**
  and add the repo title in a monospace font (JetBrains Mono, Fira Code)
